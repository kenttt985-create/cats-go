# Котики GO 🐾

Мобільна браузерна гра з мапою, користувацькими фото котів і геолокацією.

- Гравці самі додають котиків із фото й місцем на мапі.
- Підійди до котика на відстань приблизно 35 м, щоб додати його до власної колекції.
- Знаходь гравців за ніком; дружба починається тільки після прийняття запрошення.
- Приватні повідомлення доступні друзям.
- Геолокація друзів показується лише за їхнім окремим дозволом у налаштуванні «Ділитися моїм місцем із друзями».

Потрібні HTTPS, дозвіл GPS і Firebase Authentication (Email/Password) та Realtime Database. Правила бази збережені у `firebase-rules.json` і опубліковані у Firebase.

Для сайту на GitHub Pages додай файли репозиторію в корінь гілки `main`; workflow у `.github/workflows/pages.yml` автоматично опублікує сайт. Після створення адреси сайту додай її в Firebase Console → Authentication → Settings → Authorized domains.
